# Assignment 2 - k-d Tree Collision Detection

## Requirements

- Unity Hub
- Unity `6000.5.6f1`
- A Unity build-support module for the target platform

The required Unity version is also listed in `ProjectSettings/ProjectVersion.txt`.

## Opening the Project

1. Open Unity Hub.
2. Install Unity `6000.5.6f1` if it is not already installed.
3. In Unity Hub, select **Add** and choose this project directory.
4. Open the project with Unity `6000.5.6f1`.
5. Wait until Unity finishes importing assets and compiling scripts.
6. Open `Assets/Scenes/SampleScene.unity`.

## Running in the Unity Editor

1. Open `Assets/Scenes/SampleScene.unity`.
2. Press the **Play** button.
3. Click inside the Game view to focus it.

### Controls

| Input | Action |
|---|---|
| `W`, `A`, `S`, `D` | Move the player |
| Mouse movement | Rotate the camera |
| Left mouse button | Cast a ray |
| `Space` | Cast a ray |
| `K` | Show or hide the k-d tree wireframe |
